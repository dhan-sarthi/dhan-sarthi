# ADR-0009 — Contract-first: the registry is the only way a route exists

Status: Accepted
Date: 2026-09-03

## Context

CONTRIBUTING's third rule is that a route may not return a shape that is not declared in
`packages/contracts`. At adoption that package exports nothing and the API casts request bodies
without validation, so the rule is a promise. The same schemas are needed in four places: runtime
validation, the OpenAPI document a reviewer imports into Postman, the JSON Schema Runway expects
for tool definitions, and the contract tests. Maintaining them separately guarantees drift.

## Decision

`packages/contracts/src/registry.ts` is one readonly table of routes that drives runtime
validation in and out (`http/register.ts`), OpenAPI 3.1, Runway tool JSON Schema and the
contract-test matrix; a no-undeclared-route test walks Fastify's route table and fails on any
route absent from the registry.

## Alternatives

- `fastify-type-provider-zod` alone.
- Hand-maintained OpenAPI.
- Validating requests but not responses.

## Consequences

CONTRIBUTING rule 3 becomes a compile error and a test; a contract change is a visible
`openapi.json` diff in the pull request.
