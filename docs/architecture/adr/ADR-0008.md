# ADR-0008 — Opaque bearer sessions, 30-day sliding, with a HostIdentityPort seam for GO Mobile+

Status: Accepted
Date: 2026-09-03

## Context

During the review window the "customer" is whichever synthetic persona a reviewer picks; there is
no real login, and there must not be one that pretends to be. Each reviewer still needs an
isolated session with its own clock, decisions and record, returning to it a week later on the
same phone. In Phase 2 the app runs inside GO Mobile+, which will hand the WebView some host
token whose format is not yet known.

## Decision

`POST /sessions` issues a 256-bit opaque token stored as its sha256; sessions expire after 30
days idle; the persona picker is the demo's authentication. `HostIdentityPort.exchange(hostToken)`
is the named Phase-2 seam with a `NotImplemented` adapter and a WebView integration note.

## Alternatives

- JWTs. Key management for no benefit at one task sitting next to Postgres.
- 24-hour expiry. Too short for a two-week review.
- Building the SSO exchange now. The host token format is unknown.

## Consequences

Revocable, one lookup; a reviewer returning next week keeps their record; "how does this know who
the customer is inside our app" has a one-file answer.
